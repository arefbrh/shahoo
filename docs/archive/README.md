# SHAHOO document archive

The archive preserves superseded project reports and handoffs for auditability. These files are retained as historical evidence and must not be treated as the current project status, release decision or agent instructions.

## Folders

- `batch-reports/` — Batch 00–10 reports, corrections, audit snapshots and owner remediation records.
- `legacy-handoffs/` — old project-state snapshots, prompts, inventories, progress logs and interim handoffs.
- `status-reports/` — interim verification, integration, admin tracker and test summaries.
- `issue-register/` — snapshot of the previous detailed Markdown issue register.

## Current source of truth

- [Project Master Report](../PROJECT_MASTER_REPORT.md)
- [Project Handoff](../../PROJECT_HANDOFF.md)
- [Agent instructions](../../AGENTS.md)

The old documents are not deleted. Their previous “current” labels, test totals, next-step instructions and readiness statements refer to their own dated snapshots.
