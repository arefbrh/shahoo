# SHAHOO Brand Assets

The supplied ZIP contains two owner-provided logo variants in JPEG format:

- `shahoo-logo-primary.jpg`: primary brand lockup.
- `shahoo-logo-minimal.jpg`: minimal English/leaf-and-drop lockup, used for the approved invoice variant.

The repository also retains the existing PNG/WebP web assets. The original uploaded source photographs are retained in the handoff ZIP, not copied into the runtime image.

## Usage constraints

- The supplied JPEGs have a textured cream background baked in; they are not transparent PNGs.
- Do not claim these files have transparent backgrounds, redraw the logos, alter proportions, recolor, or replace one variant with the other without the owner's instruction.
- Use the minimal logo for compact UI placements where specified (including the invoice).
- Use the primary logo for brand-forward placements where appropriate.
- Preserve clear space and aspect ratio. Do not stretch or crop the symbol/wordmark.
- If a transparent/vector production master is needed, request or create a separately approved master; do not automatically remove the textured background because the cream texture may be part of the supplied artwork.
